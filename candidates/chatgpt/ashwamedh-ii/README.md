# The Missing Layer — Ashwamedh II

Independent browser-only working instrument. Open `index.html` directly or serve this folder with a static HTTP server. No dependencies, network calls, or build step.

Models the documented KB21 command tree and mount/run/release cycle, with a browser-local witness and sealed ask/correction. It does not control physical hardware.

Commands: `11` mount simulated SD card, `21` run Panel, Escape then Enter to close, `93` release. Other apps: `22` Calibrate, `23` Hello World. `91` status. Cold Reset tests reconstruction.

All original sources are linked inside the artifact; shared systems remain unchanged.
