# The Missing Layer — Ashwamedh III

**A Practitioner’s Guide to the Sciences of the Artificial**

Self-contained static website, no external dependencies or build steps. Open `index.html` directly or serve with any static file server.

Three interactive browser experiments explore elimination, structural constraints, and cold-start continuity. A local-only practitioner's card captures an ask, correction, and next test; cards can be exported as JSON and cleared locally. Six short field notes locate these instruments among the project's existing stories.

The demonstrations are simulations and do not interact with hardware, Notion, or external systems.
