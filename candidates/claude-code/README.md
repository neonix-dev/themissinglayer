# The Missing Layer

> "What I cannot create, I do not understand."

A self-governed, local-first practice for building muscle across domains. Your reps stay in your browser.

Static site: `index.html`, `style.css`, `app.js`, `sw.js`. No build step, no dependencies, no network calls.

```sh
python3 -m http.server 8300
# http://localhost:8300
```

Deploys as-is to any static host (Cloudflare Pages, GitHub Pages): publish the folder root.
